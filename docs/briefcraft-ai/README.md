# BriefCraft AI — Visual Prompt Builder

BriefCraft AI is a Chrome extension for building complete visual AI prompts and implementation briefs.

Combine goals, context, requirements, screenshots, annotated canvas objects, connected Prompt Flow nodes, links, images, and HTML/CSS/JavaScript in one local-first workspace. Copy the finished context into an AI chat, export it, save it to a folder, or optionally sync one app-created workspace file to your Google Drive.

## Key features

- Structured AI Brief Builder
- Rich text, screenshots, image paste and drag-and-drop
- Figma-like visual canvas with freehand drawing, resizable shapes, hand/pan tool, nodes and connections
- Prompt Flow ordering that is included when you use Copy for AI
- HTML/CSS/JavaScript workbench with a sandboxed live preview
- Local Chrome autosave, optional project folder, and optional Google Drive sync
- HTML, SVG, PNG, PDF, RTF, XLS, Markdown, plain text and editable BriefCraft project export
