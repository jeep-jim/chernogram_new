# Чернограм Optical 0.30.0+70

## Цель первой сборки

Проверить реальную передачу текста и небольших файлов между двумя Android-телефонами через экран и камеру без использования Wi‑Fi, Bluetooth, мобильной сети и интернета.

## Реализовано

- [x] Полностью новый Android-интерфейс Optical
- [x] Разделы «Каналы», «Файлы», «Лаборатория»
- [x] Создание комнаты и 256-битного ключа
- [x] Визуальное подключение второго устройства по статическому QR
- [x] Текстовый чат внутри комнаты
- [x] Передача файла до 2 МБ
- [x] Поток меняющихся QR-кадров
- [x] Сборка уникальных кадров камерой в произвольном порядке
- [x] Шифрование ChaCha20-Poly1305
- [x] Контроль целостности SHA-256
- [x] Локальная история комнат, сообщений и файлов
- [x] Устойчивый ID устройства
- [x] Немедленный запуск интерфейса без ожидания фоновой службы
- [x] Утверждённая маска Чернограма

## Ограничения MVP

- Передача происходит только при прямой видимости экрана камерой.
- Отправитель циклически показывает кадры до завершения приёма.
- Автоматический обратный ACK пока отсутствует.
- Fountain-кодирование пока не включено; каждый уникальный кадр должен быть принят.
- Групповой оптический чат, голос и звонки не входят в build 70.
- Максимальный размер файла ограничен 2 МБ для первого измерения скорости.

## План теста на двух Android

1. Установить один и тот же APK на оба телефона.
2. На первом создать комнату.
3. На втором отсканировать QR комнаты.
4. На втором открыть комнату и нажать кнопку камеры.
5. На первом отправить короткое сообщение.
6. Повторить тест на 5, 8 и 10 FPS.
7. Передать файлы 10 КБ, 100 КБ и 500 КБ.
8. Зафиксировать расстояние, яркость, процент кадров и время передачи.
