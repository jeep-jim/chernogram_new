# Chernogram 0.23 repair plan

Source of truth for the urgent Android and Windows repair.

## Frozen visual identity
- One approved mask/shield mark everywhere: launcher, splash, header, avatars and player.
- No cassette or alternative logo.
- Player animates only the vertical face waves inside the mask.

## Blocking defects
- Restore reliable message delivery and remove duplicate relay subscriptions/work.
- Bound every network and call operation; never freeze the UI.
- Restore invite plus application-install sharing.
- Restore permission/privacy controls.
- Restore swipe reply/forward and long-press multi-select actions for messages and files.
- Remove theme color artifacts and expensive blur work.
- Replace primitive static pattern with slow, efficient living waves.
- Produce verified Android and Windows builds from one direct source tree.

## Release rule
- Do not update the public in-app manifest until Android and Windows analyze/tests/builds pass.
