# Чернограм Transport 0.51.0+74

Цель: заменить публичные ntfy WebSocket-релеи на собственный минимальный транспорт `Импульс`, сохранив сквозное шифрование на устройстве и онлайн-обновление APK.

## Клиент

- Worker-first WebSocket для мгновенных событий.
- HTTP mailbox pull для восстановления пропущенных пакетов.
- Локальный outbox до подтверждения другим устройством.
- Повторная отправка и дедупликация packetId.
- Зашифрованные AES-GCM конверты; Worker не получает ключ комнаты.
- Сигналы звонка имеют короткий TTL.
- Текст, управление и файловые чанки имеют подтверждение доставки.
- Fallback на старый relay только пока Worker не развёрнут или недоступен.

## Worker

- Cloudflare Worker + Durable Object на комнату.
- WebSocket Hibernation API.
- Последовательный cursor для catch-up.
- Хранение только непрозрачных зашифрованных пакетов с TTL.
- Ограничение размера, количества и частоты запросов.
- Регистрация push-токенов устройства.
- Необязательная отправка FCM высокого приоритета при наличии Firebase secrets.

## Онлайн-обновление

- build 74 публикуется в `latest-apk`.
- `update.json` меняется только после успешной сборки, подписи и контрольного скачивания.
- build 73 увидит build 74 через встроенную автоматическую проверку.
- Подпись Android остаётся прежней, установка выполняется поверх приложения.

## Важное ограничение

Без Firebase-конфигурации Worker обеспечивает быстрый транспорт, mailbox и восстановление после открытия приложения. Гарантированное пробуждение полностью уснувшего Android включается после добавления Firebase client config в `transport.json` и сервисного аккаунта в secrets Worker.
