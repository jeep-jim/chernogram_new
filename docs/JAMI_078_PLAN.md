# Jami Lab 0.78

Цель — проверить Jami как реальное сетевое ядро Чернограма без регистрации пользователя, коммерческого API и собственного центрального сервера.

## Что не делаем

- не публикуем эксперимент в `main/update.json`;
- не заменяем установленный Чернограм;
- не обещаем работу сообщений или звонков до теста на двух физических телефонах;
- не используем ntfy, Stream, Firebase или самописный relay в качестве основного транспорта;
- не удаляем полноценный интерфейс ветки `fix/current-ui-working-core-061`.

## Этап 1 — сборочная проверка

1. Получить официальные исходники `jami-client-android` и `jami-daemon` с `git.jami.net`.
2. Зафиксировать точные commit SHA.
3. Найти актуальный Gradle-проект Android и JNI API daemon.
4. Получить список Gradle-модулей, вариантов и сборочных задач.
5. Проверить, можно ли собрать arm64 Android-клиент в GitHub Actions без закрытых артефактов и платных сервисов.

## Этап 2 — отдельный Jami Lab

Отдельный пакет, который ставится рядом с обычным Чернограмом:

- локальное создание Jami-профиля;
- отображение Jami ID и QR;
- добавление второго телефона по QR;
- одно текстовое сообщение;
- подтверждение доставки;
- приложение в активном состоянии, затем в фоне.

## Этап 3 — реальные ворота качества

Эксперимент считается удачным только после проверки на двух физических телефонах:

- Wi‑Fi → Wi‑Fi;
- LTE → LTE;
- Wi‑Fi ↔ LTE;
- экран получателя выключен;
- приложение получателя свёрнуто;
- повторный запуск после перезагрузки;
- аудиозвонок;
- видеозвонок;
- обрыв и восстановление сети.

Только после этого рассматривается перенос полноценного интерфейса Чернограма на Jami-core.
