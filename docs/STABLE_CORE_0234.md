# Чернограм 0.23.4 — Stable Core

Эта ветка начинается от реально опубликованной 0.23.3 и сохраняет утверждённый интерфейс 0.23 / дизайн 0.22.

## Нельзя менять

- постоянная маска-щит Чернограма;
- экраны, навигация, темы, плеер и анимация волн лица;
- обновление Android поверх установленного приложения;
- локальное шифрование комнат и содержимого.

## Обязательный состав релиза

1. Один общий realtime-сеанс приложения, мультиплексирующий все комнаты.
2. Серверный ACK, resume cursor, store-and-forward и дисковая очередь исходящих.
3. Старый ntfy-транспорт только как аварийный fallback, не как основа.
4. Фоновый Android-сервис, уведомления сообщений и полноэкранный входящий звонок.
5. Фирменная мелодия `chernogram_incoming` из ресурсов приложения.
6. WebRTC аудио/видео с собственным TURN из конфигурации сервера.
7. Файлы хранятся отдельно от JSON истории, передаются частями и продолжаются после обрыва.
8. Один аккаунт на Android и Windows; устройство имеет отдельный `deviceId`.
9. Публичный индекс открытых файлов хранит только метаданные и зашифрованную ссылку на содержимое.
10. Поиск открытых файлов работает по всему публичному индексу, а не только по уже добавленным комнатам.
11. Видеокружок отображается круглым медиаблоком без текстового облака.
12. В «Отправить приложение» показываются QR-код и обычная кнопка системной отправки.
13. Агент и ИИ не участвуют в навигации, фоне или соединении.

## Правило публикации

Публичный `latest-apk` не переключается, пока одновременно не пройдут:

- серверные тесты gateway и файлового индекса;
- Flutter analyze и tests;
- подписанный Android release;
- Windows release;
- тест двух клиентов: сообщение, файл, resume после reconnect, call invite.
