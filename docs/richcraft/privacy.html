RichCraft Privacy Policy

Last updated: August 23, 2026

RichCraft is a local-first Chrome extension for creating rich documents, visual layouts, screenshots, and user-authored HTML/CSS/JavaScript previews. This policy explains what information the extension processes, why it is needed, and where it is stored.

1. Data RichCraft processes

RichCraft processes content only when the user creates, imports, captures, pastes, drags, opens, or edits it. This may include:

  • User-generated content: document text, formatting, images, local files, canvas objects, code, project names, and editor settings.
  • Website content: selected text or a visible-tab screenshot only after the user explicitly invokes the corresponding import or capture feature.
  • Clipboard content: content the user explicitly pastes into RichCraft. RichCraft writes to the clipboard only after the user presses a Copy button.
  • Local project data: documents and settings stored in the user's Chrome profile or in a local folder explicitly selected by the user.

Chrome Web Store policy treats this local-only processing as handling user data even though RichCraft does not transmit the content to the publisher or third parties.

2. How data is used

RichCraft uses this content only to provide the user-facing editing, formatting, canvas, screenshot, code-preview, autosave, import, copy, print, local-folder, and export features requested by the user.

3. Local storage and transmission

RichCraft stores workspace data locally in the user's Chrome profile. When the user explicitly selects a project folder, RichCraft can also write project files to that folder.

RichCraft does not operate a cloud account or synchronization service. It does not transmit documents, screenshots, browsing activity, imported files, code, or project data to the publisher or to third parties.

4. Screenshot capture

RichCraft can capture the visible active tab after the user invokes the extension. It can also open Chrome's screen or window picker when the user invokes screenshot capture from the editor. The captured image is processed locally. The user can select an area and then copy it, save it as a PNG, or open it in RichCraft.

5. Code preview

HTML, CSS, and JavaScript written by the user are rendered locally in a sandboxed preview. RichCraft does not download or execute remotely hosted extension code. User-authored code may access network resources only if the user explicitly writes such behavior into the previewed document.

6. Chrome permissions

  • activeTab: provides temporary access to the active tab after the user invokes RichCraft, for visible-tab capture or selected-text import.
  • scripting: reads only the selection requested by the user from the active tab.
  • storage: keeps documents, settings, and temporary screenshot data locally.
  • contextMenus: adds a user-invoked command for importing selected page text.
  • clipboardWrite: copies a screenshot area or formatted content only after the user presses a Copy button.

RichCraft requests no persistent host permissions.

7. What RichCraft does not do

  • RichCraft does not sell, share, or transfer user data.
  • RichCraft does not use user data for advertising, profiling, credit decisions, or unrelated purposes.
  • RichCraft does not include analytics, advertising SDKs, or tracking pixels.
  • RichCraft does not collect browsing history or monitor browsing activity in the background.
  • The publisher and other humans cannot access locally stored RichCraft content through the extension.

8. Data retention and deletion

Local workspace data remains in the user's Chrome profile until the user deletes it, clears extension storage, or uninstalls the extension. Files written to a user-selected project folder remain until the user deletes them using RichCraft or normal operating-system tools.

9. Chrome Web Store Limited Use disclosure

RichCraft's use of information received from Chrome APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements. Data is used only to provide or improve RichCraft's disclosed single purpose and user-facing features.

10. Changes to this policy

If RichCraft materially changes how it processes data, this policy and the Chrome Web Store disclosures will be updated before or together with the relevant product update.

11. Contact

For privacy or support questions, use the project's GitHub issue tracker.

Do not post documents, screenshots, passwords, payment information, or other sensitive personal information in a public GitHub issue.
