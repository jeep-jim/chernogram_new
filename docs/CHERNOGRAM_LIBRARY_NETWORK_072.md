# Чернограм Library Network 0.40.0+72

## Позиционирование

Чернограм — приватная файловая сеть с чатами и звонками.

Главная сущность продукта — не сообщение, а **объект библиотеки**: файл, музыка, видео, фото, архив, документ, ссылка, заметка, голосовое сообщение или видеокружок. Объект можно хранить локально, отправить в комнату, открыть для выбранных людей, опубликовать в открытом каталоге или раздавать со своего включённого устройства.

## Главная навигация

1. **Чаты** — лёгкие комнаты, личные диалоги, звонки, кружки, медиа и файлы.
2. **Библиотека** — локальные и доступные удалённые материалы с поиском и встроенными плеерами.
3. **Интересы** — поиск близких тем и присоединение к обсуждениям.
4. **Устройства** — телефон, Windows-компьютер и другие узлы пользователя.
5. **Профиль** — приватность, тема, обновления, хранилище и публикации.

## Библиотека

Категории:

- Все
- Музыка
- Видео и кино
- Фото
- Документы
- Архивы
- Ссылки
- Голосовые
- Видеокружки

Возможности:

- индексирование вложений из чатов;
- импорт локальных файлов через системный выбор;
- полнотекстовый поиск по имени, описанию и тегам;
- фильтр по типу, комнате, владельцу, устройству и режиму доступа;
- встроенный аудиоплеер;
- встроенный видеоплеер;
- просмотр изображений и документов;
- продолжение воспроизведения;
- очередь музыки;
- скачивание удалённого объекта;
- потоковое воспроизведение с включённого компьютера;
- повторная отправка в комнату;
- публикация в открытый каталог.

## Режимы доступа

- `private` — только владелец;
- `room` — участники выбранной комнаты;
- `link` — по секретной ссылке;
- `public` — открытый глобальный каталог;
- `oneTime` — одно получение;
- `deviceOnly` — доступен, пока устройство-владелец онлайн.

## Комнаты

Интерфейс остаётся привычным и лёгким:

- список комнат и личных диалогов;
- текст, фото, видео, музыка, документы, архивы;
- видеокружки сразу круглыми без файлового облака;
- голосовые сообщения с волной и скоростью воспроизведения;
- альбомы из нескольких файлов;
- прогресс загрузки и скачивания;
- реакции;
- ответ, пересылка, выбор и удаление;
- статусы отправки, доставки и прочтения;
- онлайн-точки;
- быстрый переход из вложения в библиотеку.

## Интересы

Механика переносится из проекта `jeep-jim/margelet` Space.

Пользователь вводит тему, например `где купить мёд`. Система:

1. нормализует слова;
2. ищет буквальные совпадения;
3. вычисляет близость по общим словам;
4. учитывает тип запроса и тематическую категорию;
5. группирует максимально близкие темы;
6. предлагает существующие комнаты или создание новой темы.

Первая версия использует локальный лексический индекс. Следующая версия добавляет глобальный индекс Worker и семантические векторы.

Типы тем:

- Вопрос
- Обсуждение
- Ищу
- Предлагаю
- Куплю
- Продам
- Помогу

## Распознавание музыки

Кнопка `Распознать` записывает короткий фрагмент и создаёт акустический отпечаток.

Поиск выполняется в два этапа:

1. собственный открытый каталог Чернограма;
2. внешний провайдер, только если пользователь разрешил его в настройках.

Если композиция найдена в открытом каталоге, приложение предлагает:

- воспроизвести;
- добавить в библиотеку;
- скачать;
- открыть владельца или комнату;
- показать похожие записи.

Распознавание не должно обещать результат, пока каталог не содержит отпечаток композиции.

## Устройства и удалённый доступ

Windows-приложение становится узлом `Маяк`:

- индексирует выбранные пользователем папки;
- публикует только метаданные разрешённых объектов;
- отдаёт файл или поток после криптографической авторизации;
- синхронизирует библиотеку телефона;
- может работать как постоянный узел комнат;
- не открывает весь диск автоматически.

С телефона можно:

- искать файлы на своём компьютере;
- просматривать фото;
- слушать музыку потоково;
- смотреть видео потоково;
- скачивать файл;
- отправлять его в комнату без предварительного скачивания на телефон.

## Сеть

### GitHub Core

- исходный код;
- Actions;
- APK и Windows Releases;
- update.json;
- статические публичные индексы и документация;
- автоматическое развёртывание Worker.

### Worker `Импульс`

- регистрация устройств и push-токенов;
- краткоживущая очередь зашифрованных конвертов;
- сигнал входящего сообщения;
- сигнал входящего звонка;
- сигнализация WebRTC;
- индекс открытых комнат, тем и файлов;
- поиск доступных владельцев объекта;
- подтверждение доставки.

Worker не получает ключи комнат и не расшифровывает содержимое.

### FCM

- пробуждение Android;
- уведомления о сообщениях;
- уведомления о звонках;
- запуск получения ожидающих зашифрованных конвертов.

### WebRTC

- звонки;
- прямая передача файлов;
- потоковое аудио и видео с компьютера;
- DataChannel для доступа к удалённой библиотеке.

## Источник истины

Локальная база устройства остаётся источником истины. Серверные компоненты хранят только:

- краткоживущие зашифрованные конверты;
- публичные метаданные, явно опубликованные пользователем;
- доступность устройств;
- маршрутизацию;
- акустические отпечатки открытой музыки.

## Неподменяемые требования

- одна утверждённая маска на Android и Windows;
- прозрачный фон ярлыка;
- две темы;
- тёмная тема — графитово-сине-фиолетовый градиент, не чистый чёрный;
- профиль и ID устройства переживают обновление;
- Android и Windows используют одну логику данных;
- файлы не загружаются в открытый каталог без явного действия владельца;
- секреты Worker, FCM и подписи никогда не встраиваются в открытый репозиторий или APK.
