# BriefCraft Release Feed

Public binary-only distribution feed for BriefCraft development and future platform releases.

The product source remains in the private `jeep-jim/BriefCraft` repository. This branch contains only version manifests, checksums and release artifacts. Installed clients use immutable versioned URLs and verify SHA-256 before activation.

Platforms:

1. Web + PWA
2. Chrome extension
3. Windows desktop
4. macOS desktop
5. Android
6. iOS

Current active development channel: `briefcraft/channels/dev/chrome-extension.json`.
