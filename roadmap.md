# Чернограм — files-first 0.23.3

## Зафиксированная основа

- Интерфейс, логотип, навигация, темы и плеер остаются от утверждённой версии 0.23 с дизайн-базой 0.22.
- Публичный канал Android меняется только после анализа, тестов, release-сборки, проверки версии и постоянной подписи.
- Android versionCode: 58, чтобы обновление устанавливалось поверх кодов 55–57.

## Главный фокус

1. Мгновенный текстовый чат без блокировки интерфейса состоянием сети.
2. Надёжная доставка с локальной очередью, повтором, дедупликацией и подтверждениями ACK.
3. Передача файлов частями; содержимое файлов не хранится внутри JSON истории приложения.
4. Единый локальный поиск файлов из всех подключённых комнат.
5. Открытые файлы находятся после входа в открытую комнату по ссылке; глобального центрального каталога содержимого нет.
6. Один Chernogram ID переносится на другое устройство зашифрованным кодом; комнаты и доступ к файлам восстанавливаются вместе с ID.
7. Аудио- и видеозвонки сохраняются, но больше не блокируются надписью о подключении.
8. Плеер и распознавание музыки сохраняются.

## Убрано из активного продукта

- Агент и автоматизация.
- Конкурирующее закрытие общей сетевой сессии фоновым монитором.
- Баннеры «Подключение», «Переподключаемся» и запрет отправки/звонка по статусу сети.
- Встраивание больших base64-файлов в локальный JSON комнат.

## Следующий этап после живого теста

- Проверить Android ↔ Android: текст, файл 1 МБ, файл 10–20 МБ, позднее подключение второго устройства.
- Проверить аудио- и видеозвонки на двух реальных сетях.
- После стабильности Android собрать тот же исходный код для Windows.
- Для поиска открытых файлов за пределами уже подключённых комнат спроектировать отдельный публичный индекс метаданных без хранения содержимого файлов.
