# SVET

**Не перекидывай. Засвети.**

SVET напрямую передаёт фотографии, видео и любые файлы между Android и Windows в одной локальной сети. Без аккаунтов, облака, VPN и внешнего сервера.

## Первая альфа 0.80

- автоматический поиск устройств в одной Wi‑Fi сети;
- выбор нескольких файлов на Android и Windows;
- drag-and-drop на Windows;
- системное «Поделиться → SVET» на Android;
- предпросмотр фотографий и карточки остальных файлов;
- запрос подтверждения на принимающем устройстве;
- доверенные устройства с автоматическим приёмом;
- прямое потоковое сохранение без сжатия;
- история последних передач;
- файлы на Windows сохраняются в `Загрузки\SVET`;
- файлы на Android публикуются в `Загрузки/SVET`.

## Ограничения первой альфы

- оба устройства должны быть открыты и находиться в одной локальной сети;
- некоторые гостевые Wi‑Fi сети блокируют связь между устройствами;
- возобновление после обрыва и шифрование транспортного потока будут добавлены после проверки базовой передачи.
